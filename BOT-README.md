# Студенческий сайт и @Polytech_homework_bot

Рабочая версия запускается на Vercel через Telegram webhook и продолжает работать при выключенном компьютере. Пошаговая настройка приведена в `README.md`. Локальный `Start-bot.cmd` оставлен только для разработки и не должен работать одновременно с webhook.

## Три кнопки бота

- **Изменить расписание** → календарь → занятие → отдельный выбор переноса, изменения только времени, отмены или восстановления → подтверждение. Также можно добавить дополнительное занятие. Изменения относятся к конкретной дате и не перезаписывают обычное двухнедельное расписание.
- **Изменить домашнее задание** → предмет → просмотр текущего текста → оставить или изменить текст → вложения → дата в календаре → подтверждение. На шаге вложений можно добавить до 10 ссылок, документов или фотографий, удалить отдельные вложения и продолжить без них. Размер одного файла — до 4 МБ. Время сдачи не указывается. Кнопка «Автоматически по расписанию» находится под календарём и фиксирует дату ближайшего следующего занятия с учётом переносов. Выбранная вручную дата тоже фиксирована. При сохранении сервер также подготавливает китайский перевод текста для языкового переключателя сайта.
- **Посмотреть список заданного** — жирные названия предметов, даты и задания в одном сообщении. Длинный список перелистывается внутри сообщения.

Все шаги, кроме текста нового задания, доступны кнопками. Кнопка «Назад» располагается первой, а отмена возвращает в главное меню даже из старого сообщения.

Бот работает в публичном режиме: любой пользователь, открывший личный чат с ботом, получает все три функции и может изменять общие данные сайта. Незавершённые диалоги разных пользователей хранятся отдельно.

## Сайт

Обновление каждые 5 секунд. Ссылки открываются в новой вкладке, а прикреплённые файлы скачиваются через сервер без передачи Telegram-токена в браузер. Все вложения являются публичными. Каждое сохранённое задание сразу записывается в журнал. После дня сдачи оно автоматически исчезает из актуального списка, но остаётся в журнале и находится по предмету и дате. Изменённые дни отмечены красным и надписью «Изменено». При переносе помечаются исходный и новый день. Перелистывание недель позволяет увидеть будущие даты. Чётность недели фиксированно вычисляется по календарю; 14–20 сентября 2026 года — нечётная неделя. Даты рассчитываются для Москвы.

## Хранение

На Vercel задания, изменения расписания и состояние меню хранятся в Upstash Redis. Токен, секрет webhook и коды настройки находятся только в Vercel Environment Variables. Публичный `/api/homework` отдаёт расписание и задания, но не содержит ключей записи или секретов.

Локальный `server/private/state.json` содержит старую локальную базу, а `server/private/token.dpapi` — токен, зашифрованный Windows. Папку `server/private` не публикуйте.

Проверка всех сценариев: `npm test`.
