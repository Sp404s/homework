# Студенческий сайт и @Polytech_homework_bot

Рабочая версия запускается на Vercel через Telegram webhook и продолжает работать при выключенном компьютере. Пошаговая настройка приведена в `README.md`. Локальный `Start-bot.cmd` оставлен только для разработки и не должен работать одновременно с webhook.

## Три кнопки бота

- **Изменить расписание** → календарь → занятие → перенос, отмена или восстановление → новая дата → часы и минуты начала/окончания → подтверждение. Также можно добавить дополнительное занятие. Изменения относятся к конкретной дате и не перезаписывают обычное двухнедельное расписание.
- **Изменить домашнее задание** → предмет → новый текст (или сохранить прежний) → дата в календаре → подтверждение. Время сдачи не указывается. «Автоматически по расписанию» использует ближайшее фактическое занятие, учитывая переносы. Выбранная вручную дата фиксирована и не переносится после истечения срока.
- **Посмотреть список заданного** — жирные названия предметов, даты и задания в одном сообщении. Длинный список перелистывается внутри сообщения.

Все шаги, кроме текста нового задания, доступны кнопками. В каждом меню есть отмена. Старые меню не публикуют изменения после начала нового сценария.

Бот работает в публичном режиме: любой пользователь, открывший личный чат с ботом, получает все три функции и может изменять общие данные сайта. Незавершённые диалоги разных пользователей хранятся отдельно.

## Сайт

Обновление каждые 5 секунд. Изменённые дни отмечены красным и надписью «Изменено». При переносе помечаются исходный и новый день. Перелистывание недель позволяет увидеть будущие даты. Кнопки чётной/нечётной недели сохранены на сайте и меняют отображение только на устройстве посетителя; в боте их нет. Даты рассчитываются для Москвы.

## Хранение

На Vercel задания, изменения расписания и состояние меню хранятся в Upstash Redis. Токен, секрет webhook и коды настройки находятся только в Vercel Environment Variables. Публичный `/api/homework` отдаёт расписание и задания, но не содержит ключей записи или секретов.

Локальный `server/private/state.json` содержит старую локальную базу, а `server/private/token.dpapi` — токен, зашифрованный Windows. Папку `server/private` не публикуйте.

Проверка всех сценариев: `npm test`.
