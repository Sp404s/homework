# Студенческий сайт и @Polytech_homework_bot

Запуск: `Start-bot.cmd`. Оставьте окно открытым. Сайт: http://127.0.0.1:3210. Нельзя запускать второй экземпляр, пока первый занимает порт. Остановка: Ctrl+C в окне запуска. Для постоянной работы при выключенном компьютере нужен хостинг; текущий сервер доступен только на этом компьютере.

## Три кнопки бота

- **Изменить расписание** → календарь → занятие → перенос, отмена или восстановление → новая дата → часы и минуты начала/окончания → подтверждение. Также можно добавить дополнительное занятие. Изменения относятся к конкретной дате и не перезаписывают обычное двухнедельное расписание.
- **Изменить домашнее задание** → предмет → новый текст (или сохранить прежний) → дата в календаре → подтверждение. Время сдачи не указывается. «Автоматически по расписанию» использует ближайшее фактическое занятие, учитывая переносы. Выбранная вручную дата фиксирована и не переносится после истечения срока.
- **Посмотреть список заданного** — жирные названия предметов, даты и задания в одном сообщении. Длинный список перелистывается внутри сообщения.

Все шаги, кроме текста нового задания, доступны кнопками. В каждом меню есть отмена. Старые меню не публикуют изменения после начала нового сценария.

## Сайт

Обновление каждые 5 секунд. Изменённые дни отмечены красным и надписью «Изменено». При переносе помечаются исходный и новый день. Перелистывание недель позволяет увидеть будущие даты. Кнопки чётной/нечётной недели сохранены на сайте; в боте их нет. Даты рассчитываются для Москвы.

## Хранение

`server/private/state.json` содержит задания, изменения расписания и идентификатор владельца. `server/private/token.dpapi` содержит зашифрованный Windows токен. Папку `server/private` не публикуйте. Сервер раздаёт только файлы сайта из явного списка и API, служебные файлы недоступны.

Для разработки без Telegram: `node server/app.mjs --web-only`. Проверка сценариев: `node server/bot.test.mjs`.
