# Студенческий портал

Мобильный сайт с расписанием и домашними заданиями, которые можно изменять через Telegram-бота.

## Локальный запуск

1. Запустите `Start-bot.cmd`.
2. Не закрывайте открывшееся окно сервера.
3. Откройте <http://127.0.0.1:3210/>.

Подробная настройка Telegram-бота описана в `BOT-README.md`.

## Безопасность

Токен и рабочее состояние бота хранятся только локально в `server/private/`. Эта папка, файлы `.env` и журналы исключены из Git.
